# 定时任务模板

仅在用户明确授权配置、预算和提交订单后使用。提前检查登录、Cua连接和私有地址配置，枚举当前Chrome窗口，启动 `python run_at_release.py --plan <计划> --journal <唯一进度> --window-id <当前窗口> --submit`。

由Jev判断每个下一步，Cua执行；助手只监控简短输出。`auth_waiting`立即通知用户，认证后原进程续跑。没有可用控件、官方排队或页面加载时只等待，不刷新。模型BLOCKED、驱动异常或未知交易结果时停止并核实，不能循环重启或新建journal重试。已有完整地址直接沿用，缺少时通过本机私有配置补填，不发给模型。

到达真实支付宝并验证金额后停止，不付款，删除一次性调度。按用户约定的截止时间停止等待，不能自动在另一日期补买。不得以“准时启动”或“测试通过”声称订单成功，必须验证实际结果。

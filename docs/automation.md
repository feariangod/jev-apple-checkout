# 可复制的定时任务提示

此文件只是模板，不会创建定时任务。先在当前机器完成选配和订单确认页测试，再通过支持本机执行的调度器创建一次性任务。把下面的尖括号内容替换为你自己的值。

> 在 `<开售日期>`、时区 `<时区>`，提前10分钟准备，在开售前5分钟确认苹果中国商店登录；验证码/Touch ID需要人工处理时立即通知。使用 Jev + Cua 操作我指定的已登录 Chrome 窗口，不逐步回传截图。购买配置以 `<计划绝对路径>` 为准，预算上限为 `<金额>`。先读取现有 `<唯一交易进度路径>`；已有订单或已到支付宝不得重建进度重复购买。获取当前准确窗口编号，提前启动项目内 `.venv/bin/python run_at_release.py --plan <计划路径> --journal <唯一进度路径> --window-id <编号> --submit`。该命令会真实提交一笔订单，停在支付宝，不付款。仅在我明确授权该配置、预算及提交订单后使用 `--submit`。认证失败、驱动异常、金额不符或提交结果不明时暂停，保留进度并通知我。结束后关闭本次调度，不关闭我的浏览器窗口。

没有 Codex 也可提前在终端运行同一计时入口。必须保持电脑唤醒、解锁及网络连接；脚本不会自动解锁、读取验证码或绕过网站限制。先用 `--check` 核对日期和预算，测试时不要用真实提交标志。正式运行不得与测试任务同时操作购物袋。
